# 오늘의 식탁 · Today Table

아침·점심·저녁 메뉴를 추천하고, 선택한 음식의 재료와 조리 순서를 보여 주는 웹 앱입니다. 매일 무엇을 먹을지 고민할 때 세 가지 후보에서 한 끼를 고를 수 있도록 만들었습니다.

## 주요 기능

- 아침·점심·저녁별 추천 메뉴 3개 표시
- 총 21개 레시피: 식사 종류별 7개, 1인분 기준 재료·조리 시간·조리 순서 제공
- 기기 현지 날짜를 기준으로 매일 추천 갱신
- 3일 주기 동안 공통 메뉴 1개를 유지하고 나머지 2개를 바꾸는 추천 구성
- 레시피 상세 화면, 목록 복귀 및 Esc 키로 닫기
- 모바일 화면 대응과 상세 화면 진입·복귀 시 키보드 포커스 이동

## 실행 방법

1. 이 저장소의 **Code → Download ZIP**으로 소스를 내려받아 압축을 풉니다.
2. `index.html`을 최신 Chrome 또는 Edge에서 엽니다. JavaScript를 허용해야 합니다.
3. 별도 빌드나 패키지 설치는 필요하지 않습니다.

로컬 서버로 확인하려면 Python이 설치된 환경에서 다음 명령을 실행합니다.

```bash
git clone https://github.com/TonyU217/today-table.git
cd today-table
python -m http.server 8000
```

브라우저에서 [http://localhost:8000](http://localhost:8000)을 엽니다. 비공개 저장소는 GitHub 접근 권한이 필요합니다.

## 사용 흐름

식사 시간을 선택하고 추천 카드 중 하나를 누르면 레시피가 열립니다. 재료와 순서를 확인한 뒤 ‘메뉴로 돌아가기’ 또는 ‘나가기’로 목록에 돌아옵니다.

## 기술 구성

HTML, CSS, JavaScript를 `index.html`에 함께 담은 정적 웹 프로젝트입니다. 별도 애플리케이션 서버나 빌드 도구 없이 브라우저에서 실행합니다.

## 구현 포인트

날짜 기반 시드와 셔플을 사용해 같은 날짜·식사 종류에 같은 추천을 만듭니다. 날짜 변경은 주기적으로 확인하고, 탭이 다시 활성화될 때도 확인합니다. 레시피는 JavaScript 데이터로 관리하며 화면에는 `textContent`로 표시합니다.

## 참고 사항

현재 저장소는 사진 대신 이모지로 음식을 표시하는 21개 레시피 버전입니다. 사진 자료와 별도 다운로드 설치기는 포함되어 있지 않습니다. 추천 기준은 한국 표준시 고정이 아닌 기기의 현지 날짜입니다. 현재 화면에는 개별 메뉴 교체 버튼이 없습니다.
